# Startup Profit Analysis

An end-to-end data analytics and regression modeling project designed to evaluate startup expenditure across key departments and predict overall profitability.

## Project Overview
The objective of this project is to analyze startup financial data, identify the primary drivers of profit, build predictive regression models, and present actionable insights through an interactive dashboard and executive report.

## Repository Contents
* **`startup_dataset.xlsx`** – The dataset containing startup spending metrics (R&D Spend, Administration, Marketing Spend, State) and profit figures, along with statistical and regression calculations.
* **`Startup_dashboard.pbix`** – Interactive Power BI dashboard visualizing profit distribution, department-wise expenditure, and key performance indicators.
* **`Startup Profit Analysis.docx`** – Detailed analytical report covering methodology, regression results, key findings, and business recommendations.
* **`Startup Profit Analysis Presentation.pptx`** – Executive slide deck summarizing the project insights and visual findings.

## Tools & Technologies Used
* **Microsoft Excel:** Data cleaning, exploratory analysis, and Multiple Linear Regression modeling.
* **Power BI:** Interactive data visualization and dashboard reporting.
* **Microsoft Word & PowerPoint:** Technical documentation and executive presentation.

## Key Highlights
* Evaluated correlations between R&D, Administration, and Marketing investments against net profit.
* Built a predictive regression model to estimate expected profit based on departmental budget allocation.
* Designed a dynamic Power BI dashboard to filter and compare performance across regions and spending categories.
